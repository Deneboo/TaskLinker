# TaskLinker

Projet réalisé dans le cadre de la formation **Développeur d'application PHP/Symfony** d'OpenClassrooms.

## Prérequis

Docker
Docker Compose
Composer
Symfony CLI

## Installation

1. Cloner le dépôt :

```bash
git clone <url-du-repository>
```

```bash
cd TaskLinker
```

```bash
composer start
```

2. Démarrer le projet :

```bash
composer start
```

3. Importer les fixtures :

```bash
symfony console doctrine:fixture:load
```

## Ouvrir l'application

Une fois le serveur démarré, l'application est accessible à l'adresse suivante :

**http://localhost:8000**
